# Definition of Done

## Software Task

- [ ] Behavior implemented.
- [ ] Targeted tests pass.
- [ ] Relevant integration tests pass.
- [ ] Ruff passes.
- [ ] Relevant mypy passes.
- [ ] Logging/error behavior reviewed.
- [ ] Documentation updated.
- [ ] No secrets added.
- [ ] No unnecessary dependency added.

## Data Task

- [ ] Source documented.
- [ ] Timestamp semantics documented.
- [ ] Units documented.
- [ ] Station identity documented.
- [ ] Missing-data behavior defined.
- [ ] Validation rules implemented.
- [ ] Quality report generated.
- [ ] Raw data remains immutable.

## ML Task

- [ ] Dataset version recorded.
- [ ] Feature version recorded.
- [ ] Temporal split documented.
- [ ] Leakage checks pass.
- [ ] Baseline evaluated.
- [ ] Candidate evaluated.
- [ ] Metrics logged.
- [ ] False-negative analysis completed.
- [ ] Artifact traceable.
- [ ] Model card updated.

## Production Release

- [ ] Artifact loads.
- [ ] API schema compatible.
- [ ] Latency validated.
- [ ] Health/readiness correct.
- [ ] Monitoring present.
- [ ] Rollback available.
- [ ] Runbook updated.
