# Frontend Rules

- React/TypeScript consumes FastAPI.
- Do not place secrets in frontend.
- Do not implement ML features in browser.
- Display timestamps and units.
- Explicitly display stale/offline state.
- Distinguish observed, official forecast, and ML prediction.
- Keep map and station views readable at desktop/tablet/mobile sizes.
- Avoid excessive warning color and unnecessary UI.
