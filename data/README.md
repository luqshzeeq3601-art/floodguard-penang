# Data Directory

Pipeline stages: `raw → validated → interim → processed → model-ready`. Implemented through `processed` (canonical observations); the validated stage is `interim/quality/v1`. Model-ready tables are Phase 4.

| Path | Contents | Rules |
|---|---|---|
| `raw/jps/` | JPS Public Infobanjir payloads as received, plus raw-record/quarantine JSONL per payload | Immutable. Never edit or overwrite. Written only by `scripts/ingest_raw.py`. |
| `raw/data_gov_my/` | data.gov.my Weather API payloads (CC BY 4.0) plus JSONL | Immutable. |
| `raw/_manifest/raw_batches.jsonl` | One line per raw batch attempt (SUCCEEDED/FAILED/DUPLICATE) | Append-only. |
| `raw/metmalaysia/` | METMalaysia payloads as received | Immutable. |
| `raw/gis/` | MyGDI/JPS geospatial source files | Immutable. |
| `interim/` | Validated, normalized, quality-flagged data | Reproducible from `raw/` by code. |
| `interim/timestamps/v1/` | Normalised timestamps per raw batch (`<sha256>.timestamps.jsonl`, same relative path as the raw records) | Written only by `scripts/normalize_timestamps.py`; write-once. Policy: `docs/TIMESTAMP_POLICY.md`. |
| `interim/station_ids/v1/` | Station IDs re-resolved per raw records/quarantine file (`<sha256>[.quarantine].station_ids.jsonl`, same relative path) | Written only by `scripts/normalize_station_ids.py`; write-once. Policy: `docs/STATION_MASTER_DESIGN.md` section 12. |
| `interim/units/v1/` | Unit validation per raw records/quarantine file (`<sha256>[.quarantine].units.jsonl`, same relative path) | Written only by `scripts/validate_units.py`; write-once. Policy: `docs/UNIT_POLICY.md`. |
| `interim/quality/v1/` | Validated layer: quality flags per raw records/quarantine file (`<sha256>[.quarantine].quality.jsonl`, same relative path) | Written only by `scripts/build_historical_dataset.py` (which also writes the three component layers above with the same bytes as their scripts); write-once. `docs/QUALITY_FLAGS.md`. |
| `processed/observations/v1/<dataset_version>/` | Canonical observation table, quality summary, dataset manifest | Written only by `scripts/build_historical_dataset.py`; write-once, versioned by inputs. `docs/HISTORICAL_PIPELINE.md`. |
| `processed/` | Feature/model-ready tables | Reproducible from `interim/` by code. |
| `analysis/rainfall/<dataset_version>/` | Rainfall-distribution summary (`rainfall_distribution.json`) of one processed dataset | Written only by `scripts/analyze_rainfall.py`; write-once, git-ignored (JPS-derived). `docs/RAINFALL_DISTRIBUTION_ANALYSIS.md`. |
| `analysis/water_level/<dataset_version>/` | Water-level trend summary (`water_level_trends.json`) of one processed dataset | Written only by `scripts/analyze_water_level.py`; write-once, git-ignored (JPS-derived). `docs/WATER_LEVEL_TREND_ANALYSIS.md`. |
| `analysis/missingness/<dataset_version>/` | Missingness summary (`missingness.json`) of one processed dataset | Written only by `scripts/analyze_missingness.py`; write-once, git-ignored (JPS-derived). `docs/MISSINGNESS_OUTAGE_ANALYSIS.md`. |
| `metadata/` | Small discovery inventories (e.g. `metadata/jps/`) with README and evidence | Versioned (not git-ignored). Regenerated by scripts, never hand-edited. Exception: `metadata/*/raw/` third-party captures are git-ignored unless under a verified open licence; all are listed in `metadata/RAW_EVIDENCE_MANIFEST.csv`. |
| `metadata/licensing/evidence/` | URL, retrieval time, status, sha256 and short quotes of publishers' legal pages | Versioned. No copies of legal pages. |
| `external/` | Reference data (e.g. station metadata, thresholds) | Record source and retrieval date. |

Pipeline data files (`raw/`, `interim/`, `processed/`, `analysis/`, `external/`) are git-ignored. No bulk historical data has been acquired (JPS retrieval needs permission); the pipeline has only been run on local Phase 1 captures, outside the repository.

Raw storage policy (`docs/RAW_INGESTION_DESIGN.md`): payloads are stored byte-for-byte at
`raw/<source>/<dataset>[/<station>]/<YYYY>/<MM>/<DD>/<sha256>.<ext>` (UTC date of `retrieved_at`)
next to `<sha256>.records.jsonl` and `<sha256>.quarantine.jsonl`. Files are written
temp-then-rename and never overwritten; a repeated payload is recorded as `DUPLICATE` and writes
nothing. Raw records keep values and times as received; nothing is cleaned at this stage. JPS
payloads are ingested only from files the user supplies (no JPS network fetch without permission).

Licensing and access constraints per source (JPS data needs prior written consent; no permission
obtained yet): `docs/DATA_LICENSING_AND_ACCESS.md`. Never commit third-party raw payloads whose
rights are not granted; record their URL, `retrieved_at` and sha256 in the manifest instead.

Every derived dataset must preserve observation timestamp (`Asia/Kuala_Lumpur`), ingestion timestamp, source, station ID, unit, original value, cleaned value, quality flags, and schema version. Missing observations are never silently converted to zero.
